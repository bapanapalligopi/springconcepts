
# 1. What is a Banner?

A **banner** is simply the text (or generated image-based ASCII output) displayed when Spring Boot starts.

Example:

```text id="5g9ghn"
Application Starts

↓

Display Banner

↓

Load Spring Boot

↓

Create Beans

↓

Application Ready
```

The banner is shown **before the application context is fully initialized**.

---

# 2. Default Banner

If you do nothing, Spring Boot prints its default banner.

```text id="0fdqow"
:: Spring Boot ::
```

followed by the version number.

Flow:

```text id="ojhuxr"
Run Application

↓

Default Banner

↓

Startup Logs
```

---

# 3. Creating Your Own Banner

Create a file:

```text id="lw93p0"
src/main/resources/banner.txt
```

Spring Boot automatically looks for this file during startup.

Example:

```text id="mh01dv"
======================================
      EMPLOYEE MANAGEMENT SYSTEM
======================================
```

Output:

```text id="08kymk"
======================================
      EMPLOYEE MANAGEMENT SYSTEM
======================================
```

The default banner is replaced.

---

# 4. Using ASCII Art

Instead of plain text:

```text id="i8ck4e"

```

you can create ASCII art.

Example:

```text id="8mf7hu"

| ____|_ __ ___  _ __ | |
|  _| | '_ ` _ \| '_ \| |
| |___| | | | | | |_) | |
|_____|_| |_| |_| .__/|_|
                 |_|
```

Spring Boot prints it exactly as written.

# 5. Creating ASCII Art


# 6. Image Banner

Spring Boot can also generate a banner from an image.

Supported formats include:

```text id="0h3vje"
banner.gif

banner.jpg

banner.png
```

Place the file in:

```text id="d4gfk4"
src/main/resources
```

During startup:

```text id="fvx1lr"
Image

↓

Convert to ASCII

↓

Display in Console
```

**Note:** Image banners are less common today because console output varies across environments.

# 7. Programmatic Banner

Instead of `banner.txt`, you can define a banner in Java.

Example:

```java
@SpringBootApplication
public class EmployeeApplication {

    public static void main(String[] args) {

        SpringApplication app =
                new SpringApplication(EmployeeApplication.class);

        app.setBanner((environment, sourceClass, out) -> {
            out.println("===== EMPLOYEE API =====");
        });

        app.run(args);
    }
}
```

Output:

```text
===== EMPLOYEE API =====
```

This approach is useful when the banner needs to be dynamic.

---

# 8. Disabling the Banner

Sometimes you don't want any banner.

Disable it in `application.properties`:

```properties
spring.main.banner-mode=off
```

Flow:

```text id="9s4lmd"
Application Starts

↓

No Banner

↓

Startup Logs
```

Or programmatically:

```java
SpringApplication app =
        new SpringApplication(EmployeeApplication.class);

app.setBannerMode(Banner.Mode.OFF);

app.run(args);
```

---

# 9. Banner Modes

Spring Boot supports three modes.

| Mode      | Description                            |
| --------- | -------------------------------------- |
| `console` | Prints banner to the console (default) |
| `log`     | Writes banner to the application log   |
| `off`     | Disables the banner                    |

Example:

```properties
spring.main.banner-mode=log
```

Flow:

```text id="7tpgkp"
Application Starts

↓

Banner Written to Log File
```

---

# 10. Banner Variables

Spring Boot allows placeholders inside `banner.txt`.

Example:

```text
Application: ${application.title}
Version: ${application.version}
Spring Boot: ${spring-boot.version}
```

If the values are available, Spring replaces them during startup.

Example output:

```text
Application: Employee API
Version: 1.0.0
Spring Boot: 3.x.x
```

# 13. Common Mistakes

### Mistake 1

Placing the file in the wrong location.

Wrong:

```text
src/banner.txt
```

Correct:

```text
src/main/resources/banner.txt
```

---

### Mistake 2

Expecting the banner to affect application behavior.

It doesn't.

The banner is **only for display**.

---

### Mistake 3

Using huge banners.

Very large banners make startup logs harder to read.

Keep them concise.

---

# 14. Best Practices

```text id="0k4u6s"
✅ Keep banners small and readable

✅ Include application name

✅ Include version when useful

✅ Disable banners if startup logs become noisy

❌ Don't rely on banners for important operational information

❌ Don't make banners excessively large
```

# 15. Interview Questions

### What is the Spring Boot banner?

> The banner is the text displayed when a Spring Boot application starts.

---

### Where is the custom banner stored?

> In:

```text
src/main/resources/banner.txt
```

---

### Can we disable the banner?

Yes.

```properties
spring.main.banner-mode=off
```

---

### Can we create a banner programmatically?

Yes, by configuring a `SpringApplication` instance and calling `setBanner(...)`.

---

### Does the banner affect application performance?

No. It is only displayed during startup and has no effect on runtime behavior.
